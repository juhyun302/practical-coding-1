# Favorite Music Node/Firebase API

Express와 Firebase Admin SDK로 구현한 즐겨찾기 REST API입니다. Firestore에 좋아하는 앨범을 저장합니다.

## Setup

1. Firebase 서비스 계정 JSON을 `firebaseKey.json`으로 저장합니다.
2. 키 파일은 Git에 포함하지 않습니다.
3. 의존성을 설치하고 서버를 실행합니다.

```bash
npm install
node app.js
```

서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.
