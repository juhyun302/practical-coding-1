# Course Repository Map

학교 GitLab에 나뉘어 있던 실전코딩1 저장소를 다음과 같이 통합했습니다.

| 원본 저장소 | 통합 위치 | 학습 주제 |
| --- | --- | --- |
| `git-basic`, `git-basic-merge`, `git-basic-merge-Yerin`, `git-exercise-fork-merge-request` | `labs/git-collaboration` | Git 기본, merge, fork, merge request |
| `first-maven` | `labs/java-maven` | Maven과 JUnit |
| `springboot-tutorial` | `labs/spring-boot-basics` | Spring Boot, JPA, MySQL/H2 |
| `myflutter` | `labs/flutter-namer` | Provider, 반응형 navigation |
| `myflutter2` | `labs/flutter-navigation` | 화면 이동과 StatefulWidget |
| `favorite_flutter` | `projects/favorite-music/flutter-client` | Flutter UI, 상태 관리, HTTP |
| `MySpringWeb` | `projects/favorite-music/spring-api` | Spring REST API, JPA |
| `nodejs-firebase` | `projects/favorite-music/node-firebase-api` | Express, Firebase Admin |
| `SpringMarkdown` | `projects/spring-markdown-viewer` | Markdown parsing, Thymeleaf |
| `todo-ai-practice` | `projects/ai-todo-cli` | Python, JSON, pytest, AI review |

원본 저장소의 최신 결과물을 기준으로 정리했으며, 개인정보와 로컬 비밀번호, 빌드 결과물은 제외했습니다.
