# Git Collaboration Lab

실전코딩1 초반에 수행한 Git 실습을 개념 중심으로 정리했습니다.

## What I Practiced

- 로컬 저장소 생성과 원격 저장소 연결
- add, commit, push를 이용한 변경 이력 관리
- branch 생성과 merge
- 다른 저장소 fork
- merge request를 이용한 협업
- 충돌이 발생했을 때 변경 내용을 비교하고 해결하는 흐름

원본 저장소는 결과 파일이 매우 작고 개인정보가 포함되어 있어, 포트폴리오에는 파일을 그대로 복제하지 않고 학습 내용만 남겼습니다.
